Not every game works for every person. Someone in early-stage dementia who was a musician might love Name That Tune but find Picture Match boring. Someone in later stages might find Bingo perfect but Finish the Pattern overwhelming.

Here's how to find what works.

## Start with their history

Think about what they enjoyed before dementia:
- **Card players** → Memory Match, Simple Pairs, Tic Tac Toe
- **Puzzle lovers** → Sunday Paper (word search), Finish the Pattern, Line Builder
- **Music lovers** → Name That Tune, Tap Along, Copy the Melody, Juke Box
- **Social/community** → Bingo (the "BINGO!" moment triggers community hall memories)
- **Practical/hands-on** → Tool Shed, Put Things Away, Recipe Box
- **Nature lovers** → Relaxation games (Ripple Pond, Forest Rest)

## Match to their stage

### Maintenance mode (early stage)
All games are available. Start with:
- **Sunday Paper** — word search exercises language and scanning
- **Finish the Pattern** — sequencing challenges executive function
- **Word Reveal** — letter guessing exercises language recall
- **Phrase Fortune** — phrase completion triggers semantic memory

### Support mode (moderate stage)
Focus on visual and auditory games:
- **Bingo** — familiar, joyful, always succeeds
- **Picture Match** — simple visual recognition
- **Tap Along** — rhythmic, sensory, low cognitive demand
- **Colour Match** — concrete, visual, stored in long-term memory
- **Juke Box** — hear a sound, pick what made it

### Comfort mode (later stage)
Engagement itself is the goal:
- **Bingo** at Level 1 (2×2 grid — only 4 items)
- **Tap Along** — any tap makes music, no wrong answer possible
- **Relaxation games** — Ripple Pond (touch water, watch fish), Bubble Pop, Forest Rest
- **Picture Match** at Level 1 (only 2 options)

## Use the playlist feature

![Spark playlist editor](/assets/images/articles//playlist-editor.png)


Once you know which games work, create a custom playlist:
1. Tap the edit icon on their profile card
2. Scroll to "Custom Game Playlist"
3. Toggle it on
4. Add their favourite games
5. Drag to reorder (put the best one first)
6. Save

Now when they play, they only see their games — no overwhelming list of 23 options.

## Rotate over time

What works today may not work in 3 months. Check the session history periodically:
- If a game they used to enjoy now triggers more hints → they may have progressed past it. Move to a simpler game.
- If they finish games too quickly without hints → they might be ready for something more challenging.
- If they always choose the same game → that's fine. Familiarity is comforting. But occasionally introduce one new game alongside their favourite.

## Games by cognitive domain

![Brain regions and games](/assets/images/articles//brain-game-regions.png)


If a healthcare professional has identified specific areas to exercise:

| Cognitive area | Games |
|---------------|-------|
| Visual memory | Memory Match, Simple Pairs |
| Visual scanning | Bingo, Picture Match, Odd One Out |
| Auditory memory | Sound Match, Copy the Melody |
| Language/semantic | Word Reveal, Phrase Fortune, Sunday Paper |
| Executive function | Put Things Away, Careful Sorting, Finish the Pattern |
| Motor/rhythm | Tap Along, Path Finder |
| Problem solving | Tool Shed, Recipe Box, Line Builder |
| Relaxation/regulation | Ripple Pond, Bubble Pop, Forest Rest |

## The "Recommended" badge

Spark shows a green ★ badge on games it recommends based on:
- Their care mode (Comfort mode only shows all-stage games)
- Games they haven't tried yet (variety)
- Games that match their engagement history

Trust the recommendations as a starting point, then adjust based on what you observe.
